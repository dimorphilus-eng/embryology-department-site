# Кафедра эмбриологии и биологии развития

Двуязычный сайт кафедры: русский и английский, Next.js (App Router), TypeScript, Tailwind CSS и компоненты в духе shadcn/ui. Сейчас это законченный каркас с демонстрационным наполнением Академического университета. Перед публичным запуском замените имена, контакты, гранты и список работ.

## Информационная архитектура

Главное меню короткое. Наука и образование раскрываются, чтобы не плодить одинаковые страницы в шапке.

| Раздел | Адрес | Что внутри |
| --- | --- | --- |
| Главная | `/ru`, `/en` | Позиционирование, ряд развития, направления, новости, публикации, аудитории, партнёры |
| О кафедре | `/about` | История, миссия, заведующий, структура |
| Сотрудники | `/people`, `/people/[slug]` | Карточки, фильтр по должности и направлению, профиль с ORCID и Scopus |
| Наука | `/research` | Шесть направлений |
| Проекты | `/research/projects` | Гранты и статусы |
| Лаборатории | `/research/labs` | Три лаборатории |
| Публикации | `/research/publications` | Фильтр по году и автору |
| Диссертации | `/research/dissertations` | Защищённые работы, специальность 1.5.23 |
| Образование | `/education` | Бакалавриат, магистратура, аспирантура |
| Курсы | `/education/courses` | Дисциплины и ссылки на PDF |
| Расписание | `/education/schedule` | Образец недели. Заменяется ссылкой или виджетом |
| Материалы | `/education/materials` | Скачиваемые PDF |
| Практики | `/education/internships` | Виды практик и шаги заявки |
| Студентам | `/students` | Поступление, общество, участие в исследованиях, FAQ |
| Новости | `/news`, `/news/[slug]` | Новости, семинары, конференции, защиты. Тексты в MDX |
| Ресурсы | `/resources` | Внешние базы и полка PDF |
| Контакты | `/contacts` | Адрес, карта, форма, Telegram |
| Поиск | `/search` | Сотрудники, работы, курсы, новости, разделы |

Переключатель языка сохраняет путь. Версия для слабовидящих в верхней полосе меняет размер шрифта, схему (обычная, чёрным по белому, белым по чёрному, жёлтым по чёрному), интервал, изображения и подчёркивание ссылок. Настройка хранится в браузере.

## Как устроен код

- `app/[locale]` — страницы. Общие chrome: `components/layout`.
- `content/*.ts` и `content/documents.json` — структурированные данные. Страницы не ходят в них в обход типов.
- `content/articles/*.mdx` — новости. В одном файле оба языка: фронтматтер, затем `:::ru` и `:::en`.
- `lib/articles.ts` читает MDX. `components` для MDX лежат в `lib/mdx.tsx` (`Callout`).
- `lib/search.ts` собирает поисковый индекс.
- Карточки сотрудников: `components/people/people-browser.tsx`.
- Список публикаций: `components/publications/publication-browser.tsx`.
- Лента новостей: `components/news/news-browser.tsx`.
- Формы пишут в `app/api/contact` и `app/api/subscribe`. Они проверяют поля и ничего не сохраняют.

Схема рассчитана на замену файлов клиентом Sanity или Strapi. Оставьте типы `Person`, `Publication`, `Course`, `Article` и функции, которые их отдают. Страницы менять не нужно: они уже получают готовые поля на текущем языке.

Рекомендуемые коллекции CMS:

- `person`, `publication`, `project`, `lab`, `dissertation`, `course`, `program`
- `article` для новостей (portable text или MDX)
- singleton `department` для адреса, миссии, истории и FAQ

ORCID и Scopus подключены ссылками `https://orcid.org/{id}` и `https://www.scopus.com/authid/detail.uri?authorId={id}`. Идентификаторы в карточках учебные.

Schema.org: образовательная организация на каждой странице, `Person` в профиле, `NewsArticle` в новости, `FAQPage` у студентов, `BreadcrumbList` в шапке раздела. У страниц есть title, description, canonical, hreflang и Open Graph.

Индексация включена. Пока наполнение демонстрационное, задайте `SITE_INDEXABLE=false`, чтобы закрыть сайт от поисковиков. Адрес сайта берётся из `NEXT_PUBLIC_SITE_URL`.

## Как наполнять

1. Кафедра, адрес, карта, телефон, почта, Telegram: `content/site.ts`. Координаты — `site.map`.
2. Сотрудник: объект в `content/people.ts`. Поле `photo` можно добавить позже и вывести в `Monogram`. Слаг станет адресом профиля.
3. Направление, проект, лаборатория, публикация, диссертация: `content/research.ts`. У публикации `authorSlugs` должны совпадать со слугами людей, иначе фильтр по автору её не найдёт.
4. Программа, курс, расписание, практика: `content/education.ts`.
5. PDF: запись в `content/documents.json`, затем `npm run pdfs`. Скрипт кладёт файлы в `public/documents/{slug}.ru.pdf` и `{slug}.en.pdf`. Нужны шрифты Liberation Sans. На другой машине положите TTF и поправьте пути в `scripts/generate-pdfs.mjs`, либо замените готовые файлы.
6. Новость: новый файл `content/articles/slug.mdx`.

```mdx
---
slug: spring-seminar
date: 2026-03-12
kind: seminar
title:
  ru: Заголовок
  en: Title
excerpt:
  ru: Короткий лид
  en: Short lead
place:
  ru: Аудитория 214
  en: Room 214
---

:::ru

Текст. Можно вставить <Callout>выделенный абзац</Callout>.

:::en

Body.
```

`kind`: `news`, `seminar`, `conference`, `defense`. Дата в формате `YYYY-MM-DD`. Событие с датой не раньше сегодняшнего дня помечается как предстоящее при сборке.

Подписи интерфейса, не относящиеся к содержанию кафедры, лежат в `content/messages.ts`. Английский объект проверяется типом русского.

## Запуск

```bash
npm install
npm run pdfs
npm run dev
```

Сборка и проверка:

```bash
npm run lint
npm run build
npm start
```

Нужен Node.js 20 или новее.

## Развёртывание

Подойдёт любой Node-хостинг.

```bash
npm ci
npm run build
npm start
```

Переменные:

- `NEXT_PUBLIC_SITE_URL` — публичный адрес с протоколом, без завершающего слэша. От него зависят canonical, sitemap и Open Graph.
- `SITE_INDEXABLE=false` — закрыть индексацию, пока тексты не заменены.

На Vercel команда сборки `npm run build`, корневая папка — репозиторий. PDF уже лежат в `public/documents`, отдельно их генерировать на сервере не нужно.

Почта. Сейчас `app/api/contact/route.ts` и `app/api/subscribe/route.ts` отвечают успехом после проверки и не пишут письмо. Подставьте туда вызов университетского SMTP или сервиса рассылки. Не логируйте текст письма. Форма честно говорит посетителю, что демонстрационная версия ничего не отправляет.

Расписание. Страница `/education/schedule` рисует неделю из `content/education.ts`. Для боевого расписания оставьте ссылку на систему университета или вставьте виджет в эту страницу.

## Что заменить до показа наружу

- Название университета, института и кафедры, если оно другое.
- Адрес, телефон, почту, Telegram и точку на карте.
- Фотографии сотрудников вместо монограмм.
- ORCID, Scopus и настоящие DOI. Сейчас DOI вида `10.0000/demo...` никуда не ведут, а в названии издания стоит пометка «образец».
- Шифры грантов.
- Список партнёров.
- PDF программ утвержденными файлами.

В подвале на обеих языках есть короткая пометка, что наполнение демонстрационное. Уберите её, когда данные станут настоящими: текст `demoNote` в `content/messages.ts`.
